# Fisherman's Island

A pixel-art idle desktop game built in Godot 4.7. Fishermen live on an island, autonomously
walking to the dock to fish, and are equipped, leveled, and expanded by the player over time
while the game keeps running — including while it's closed.

## Status

Playable prototype with a full core loop: hire and equip fishermen, watch them fish through a
day/night and seasonal cycle, manage a 120-species fish catalog across 10 habitats, and progress
through meta-upgrades and a hidden Secret fish tier. See [Project structure](#project-structure)
below for where each system lives, or the [wiki](../../wiki) for deeper design notes.

## Tech stack

- [Godot 4.7](https://godotengine.org/) (GDScript)
- Pixel art generated by small Python scripts in `tools/` rather than hand-painted — see
  [Generated art](#generated-art) below.

## Running the project

Open this folder as a project in the Godot editor, then run the `Main` scene
(`scenes/main/Main.tscn`), or launch straight from the `MainMenu` scene for the normal game flow.

## Core loop

Each fisherman walks to the dock, fishes for a randomized duration, and walks home to rest before
repeating — all visible on screen, not just simulated. While fishing, a species and its weight are
rolled based on the fisherman's Luck and Power stats, current gear, and the world's weather,
season, and time of day. Common and Uncommon catches sell automatically for Coins; anything Rare
or above lands in the **Dock** (capped at 60 items) so the player can choose to sell it for Scales
or hold onto it.

Closing the game doesn't pause it: on reload, elapsed real time (capped at 12h, at reduced
efficiency) is resolved into a batch of offline catches per fisherman, summarized on a
"Welcome back" screen.

## Systems

- **Fishermen** — hired from a growing roster (up to 30), each with independently leveled
  Speed/Luck/Power stats, a random pixel-art appearance (`tools/generate_fisherman_sprites.py`,
  4-directional movement), 1–2 permanent perks rolled at hire time, and a capped rolling log of
  recent catches.
- **Gear** — a 200+ item shop catalog across 5 slots (Rod/Hat/Outfit/Charm/Bait), rotating stock,
  themed multi-piece set bonuses, and a handful of unique-mechanic items (guaranteed-rare bait,
  rest-skipping charms) that sit outside the normal additive-bonus system.
- **Fish** — see [`scripts/fish_catalog.gd`](scripts/fish_catalog.gd) and the
  [wiki](../../wiki/Fish) for the full catalog.
- **The world clock** — nested day/night, weather, and season cycles that bias Luck/Speed/Power
  and gate certain species and gear to specific conditions.
- **Meta-progression** — a small permanent-upgrade shop (extra fisherman slot, global Luck, shop
  discount, Coin gain, offline efficiency) paid for with Scales, independent of any one
  fisherman's gear.
- **Album** — a discovery log for every fish species, browsable by rarity tier or by habitat, with
  per-species stats, flavor text, and a record-holder line for the heaviest catch of each species.
- **Developer console** (`~` or F1, debug builds only) — fast-forwards world time, forces a
  weather type, grants currency, forces a catch of a given rarity, and simulates an offline
  session, so every system above is testable without waiting out real minutes or hours.

## Generated art

Both the fisherman and fish sprites are generated rather than hand-painted, from small Python
scripts under `tools/` using [Pillow](https://pillow.readthedocs.io/):

- `generate_fisherman_sprites.py` builds one 48×72 sheet per appearance variant (a 3×3 grid of
  16×24 frames: stand/walk-A/walk-B poses × down/right/up facings, "left" mirrored at runtime) from
  readable ASCII pixel maps and a per-variant palette.
- `generate_fish_sprites.py` builds two aligned 256×64 atlases (8×4 grid of 32×16 frames): a
  full-color body and a separate white outline mask. The Album tints the outline mask with a
  fish's rarity color at runtime rather than tinting the body, so the generated colors stay clean.

Re-run either script after editing it to rebake the corresponding `assets/sprites/` atlas; the
game reads the atlases directly and never slices or recolors art at runtime beyond that one
outline tint.

## Project structure

- `scenes/` — Godot scenes (`main/` the game itself, `entities/` the fisherman, `ui/` shared
  components, `main_menu/`)
- `scripts/` — GDScript source: autoload singletons for global state (`economy.gd`,
  `world_clock.gd`, `album.gd`, `dock_inventory.gd`, `meta_progress.gd`, `dev_console.gd`, ...) and
  per-scene controllers alongside the scenes that use them
- `assets/` — generated sprites, tilesets, and the UI theme
- `tools/` — Python art generators (see [Generated art](#generated-art))

## Saving

Autosaves every 30 seconds and on menu/quit, to Godot's user data directory
(`user://savegame.json`). There's no manual save slot management yet — one save per install.
